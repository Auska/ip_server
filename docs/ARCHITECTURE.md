# 架构设计文档

## 1. 系统概述

IP 位置信息查询服务端是一个基于 C++20 开发的高性能 RESTful API 服务，用于查询 IP 地址的地理位置信息和 AS（自治系统）信息。

### 1.1 核心功能

- IP 地理位置查询（国家、城市、经纬度、时区等）
- AS 信息查询（自治系统编号和组织名称）
- 支持单个 IP 查询和批量查询
- 日志文件轮转
- 速率限制
- API 认证
- 性能监控

### 1.2 技术栈

- **编程语言**: C++20
- **构建系统**: CMake 3.20+
- **HTTP 服务器**: cpp-httplib
- **数据库**: MaxMind GeoLite2 (City + ASN)
- **JSON 处理**: nlohmann/json
- **加密**: OpenSSL
- **测试框架**: Google Test
- **性能测试**: Google Benchmark

## 2. 系统架构

### 2.1 分层架构

系统采用经典的分层架构设计，遵循 SOLID 原则：

```
┌─────────────────────────────────────────────────────────┐
│                    HTTP Layer                            │
│              (IPGeoHTTPServer)                           │
│  - RESTful API 路由                                      │
│  - 请求/响应处理                                         │
│  - CORS 支持                                             │
│  - 速率限制                                              │
│  - API 认证                                              │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│                  Service Layer                           │
│                (IPGeoService)                            │
│  - 业务逻辑处理                                          │
│  - 缓存管理                                              │
│  - 查询协调                                              │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│                   Data Layer                             │
│        (CityDatabase, ASNDatabase)                       │
│  - 数据库访问                                            │
│  - 数据解析                                              │
│  - 错误处理                                              │
└────────────────────┬────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────┐
│              MaxMind DB Library                          │
│              (libmaxminddb)                              │
│  - MMDB 文件读取                                         │
│  - 二进制数据解析                                        │
└─────────────────────────────────────────────────────────┘
```

### 2.2 模块设计

#### 2.2.1 HTTP 层 (http_server.h/cpp)

**职责**:
- 处理 HTTP 请求和响应
- 实现 RESTful API 路由
- 应用速率限制
- 处理 API 认证
- 收集性能指标

**主要类**:
- `IPGeoHTTPServer`: HTTP 服务器主类

**关键方法**:
- `start()`: 启动服务器
- `stop()`: 停止服务器
- `set_lookup_handler()`: 设置查询处理器
- `setup_routes()`: 配置路由

**路由配置**:
```cpp
GET  /                    # 服务信息
GET  /health              # 健康检查
GET  /metrics             # 性能指标
GET  /lookup?ip=<addr>    # 单个 IP 查询
POST /lookup              # 批量查询
```

#### 2.2.2 服务层 (database.h/cpp)

**职责**:
- 实现业务逻辑
- 管理缓存
- 协调数据库查询
- 统一数据格式

**主要类**:
- `IPGeoService`: 服务主类
- `CityDatabase`: 城市数据库
- `ASNDatabase`: AS 数据库
- `MaxMindDatabase`: 数据库基类

**关键方法**:
- `lookup(ip)`: 查询单个 IP
- `batch_lookup(ips)`: 批量查询
- `is_city_db_open()`: 检查城市数据库状态
- `is_asn_db_open()`: 检查 AS 数据库状态

**缓存策略**:
- 使用 LRU 缓存
- 默认缓存大小：10,000 条记录
- 缓存命中率可达 95%+

#### 2.2.3 配置层 (config.h/cpp)

**职责**:
- 解析命令行参数
- 加载配置文件
- 验证配置有效性
- 管理 XDG 目录

**主要类**:
- `ServerConfig`: 服务器配置结构体
- `ConfigParser`: 配置解析器

**配置项**:
```cpp
struct ServerConfig {
    std::string host;                          // 监听地址
    uint16_t port;                            // 监听端口
    std::string city_db_path;                 // 城市数据库路径
    std::string asn_db_path;                  // AS 数据库路径
    int thread_pool_size;                     // 线程池大小
    size_t cache_size;                        // 缓存大小
    bool enable_rate_limiter;                 // 启用速率限制
    int max_requests_per_minute;              // 每分钟最大请求数
    int max_batch_size;                       // 批量查询最大大小
    bool enable_api_auth;                     // 启用 API 认证
    std::string api_keys_file;                // API 密钥文件
    std::string default_api_key;              // 默认 API 密钥
    bool enable_file_logging;                 // 启用文件日志
    std::string log_file_path;                // 日志文件路径
    std::string log_rotation_type;            // 日志轮转类型
    size_t log_max_file_size;                 // 日志最大文件大小
    int log_rotation_interval_minutes;        // 日志轮转间隔
    int log_max_backup_files;                 // 最大备份文件数
    bool log_enable_stdout;                   // 启用标准输出
};
```

#### 2.2.4 日志层 (logger.h/cpp)

**职责**:
- 提供日志记录功能
- 支持文件日志和标准输出
- 实现日志文件轮转
- 支持多级别日志

**主要类**:
- `Logger`: 日志器主类
- `AsyncLogger`: 异步日志器
- `LogConfig`: 日志配置

**日志级别**:
```cpp
enum class LogLevel {
    DEBUG,    // 调试信息
    INFO,     // 一般信息
    WARNING,  // 警告信息
    ERROR     // 错误信息

```

**日志轮转类型**:
```cpp
enum class RotationType {
    NONE,     // 不轮转
    SIZE,     // 按大小轮转
    TIME,     // 按时间轮转
    BOTH      // 同时按大小和时间轮转

```

**异步日志架构**:
```
┌─────────────┐
│  Logger     │
│  (同步接口)  │
└──────┬──────┘
       │ log()
       ▼
┌─────────────┐
│ AsyncLogger │
│ (工作线程)   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  stdout     │
└─────────────┘
```

#### 2.2.5 速率限制层 (rate_limiter.h/cpp)

**职责**:
- 实现 IP 级别的速率限制
- 使用滑动窗口算法
- 防止滥用

**主要类**:
- `RateLimiter`: 速率限制器

**算法**:
- 滑动窗口算法
- 时间窗口：1 分钟
- 默认限制：100 请求/分钟

#### 2.2.6 认证层 (auth.h/cpp)

**职责**:
- 实现 API 密钥认证
- 支持多个 API 密钥
- 提供默认密钥用于测试

**主要类**:
- `AuthManager`: 认证管理器

**认证方式**:
- HTTP Header: `X-API-Key: your_key`
- Query Parameter: `?api_key=your_key`

#### 2.2.7 监控层 (metrics.h/cpp)

**职责**:
- 收集性能指标
- 提供指标查询接口
- 监控服务健康状态

**主要类**:
- `Metrics`: 指标收集器

**指标类型**:
- 请求计数
- 响应时间
- 缓存命中率
- 数据库状态

#### 2.2.8 XDG 目录层 (xdg.h/cpp)

**职责**:
- 管理 XDG 目录标准
- 提供配置、数据和缓存目录路径

**主要类**:
- `XDGPaths`: XDG 路径管理器

**目录结构**:
```

~/.cache/ip-server/       # 缓存文件
```

## 3. 数据流

### 3.1 单个 IP 查询流程

```
Client
  │
  │ 1. GET /lookup?ip=8.8.8.8
  ▼
HTTP Server
  │
  │ 2. 速率限制检查
  ▼
Auth Manager
  │
  │ 3. API 认证检查
  ▼
HTTP Server
  │
  │ 4. 调用查询处理器
  ▼
IPGeoService
  │
  │ 5. 检查缓存
  ▼
Cache (Hit?)
  │
  ├─ Yes ──▶ 6. 返回缓存结果
  │
  └─ No ──▶ 7. 查询数据库
              ▼
         CityDatabase
              │
              │ 8. 查询城市信息
              ▼
         ASNDatabase
              │
              │ 9. 查询 AS 信息
              ▼
         10. 更新缓存
              ▼
         11. 返回结果
  ▼
HTTP Server
  │
  │ 12. 构建 JSON 响应
  ▼
Client
```

### 3.2 批量查询流程

```
Client
  │
  │ 1. POST /lookup
  │    {"ips": ["8.8.8.8", "1.1.1.1"]}
  ▼
HTTP Server
  │
  │ 2. 解析 JSON 请求
  ▼
IPGeoService
  │
  │ 3. 遍历 IP 列表
  ▼
For each IP:
  │
  ├─▶ 检查缓存
  │
  ├─▶ 查询数据库
  │
  └─▶ 更新缓存
  ▼
  │ 4. 收集所有结果
  ▼
  │ 5. 构建 JSON 数组响应
  ▼
HTTP Server
  │
  │ 6. 返回响应
  ▼
Client
```

## 4. 并发模型

### 4.1 线程池

HTTP 服务器使用线程池处理并发请求：

```
┌─────────────────────────────────────┐
│         HTTP Server                 │
│  (主线程 - 接受连接)                │
└──────────┬──────────────────────────┘
           │
           ▼
┌─────────────────────────────────────┐
│         Thread Pool                 │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐  │
│  │ T1  │ │ T2  │ │ T3  │ │ T4  │  │
│  └─────┘ └─────┘ └─────┘ └─────┘  │
│  (工作线程 - 处理请求)              │
└─────────────────────────────────────┘
```

**特点**:
- 默认线程数：4
- 可配置：`--threads N`
- 每个线程独立处理请求
- 线程安全的缓存访问

### 4.2 线程安全

**互斥锁保护**:
- 缓存访问
- 日志文件写入
- 指标更新

**无锁设计**:
- 数据库查询（只读）
- HTTP 请求处理（每请求独立）

## 5. 性能优化

### 5.1 缓存策略

**LRU 缓存**:
- 最近最少使用算法
- 默认大小：10,000 条
- 可配置：`--cache-size N`

**缓存效果**:
- 命中率：95%+
- 响应时间：~1.56μs (命中)，~13.5μs (未命中)
- QPS：647k (Release 模式)

### 5.2 异步日志

**异步日志架构**:
```
主线程 ──▶ 日志队列 ──▶ 工作线程 ──▶ 文件/标准输出
```

**优势**:
- 不阻塞主线程
- 提高响应速度
- 批量写入提高效率

### 5.3 数据库优化

**内存映射**:
- MaxMind 数据库使用内存映射
- 快速随机访问
- 低内存占用

**预加载**:
- 启动时打开数据库文件
- 避免首次查询延迟

**错误响应格式**:
